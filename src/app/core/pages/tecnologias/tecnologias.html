Tecnologías de testing

Estas herramientas no se sustituyen por completo entre sí. Muchas conviven hoy según el tipo de proyecto y el objetivo de cada prueba.

Mocha + Chai

Se usa mucho en ecosistema Node. Mocha organiza y ejecuta suites; Chai aporta aserciones expresivas como to.equal.

Karma

Es un test runner: no define aserciones, sino que lanza pruebas en navegadores reales usando frameworks como Jasmine o Mocha.

Cypress y Playwright

Ambos cubren flujos E2E. Cypress destaca por DX visual en el navegador; Playwright por paralelismo, multi-navegador y trazas más completas en CI.

Línea de tiempo de tecnologías

Cada etapa resolvió un problema concreto: velocidad, estabilidad o mantenibilidad. Por eso evolucionaron, pero no desaparecieron.

1998-2009

Scripts ad-hoc y validación manual

Sirvió para arrancar, pero escalar era difícil y las regresiones escapaban. Cobertura limitada y lenta. 

const saveBtn = document.querySelector('#save');
saveBtn?.dispatchEvent(new MouseEvent('click'));

console.assert(
	document.querySelector('.toast')?.textContent === 'Guardado'
);

2010-2015

Jasmine + Karma para unitarias en navegador

Se consolidó describe/it con feedback rápido. Karma actúa como runner que ejecuta suites de Jasmine (u otros) en navegadores reales. 

describe('PricePipe', () => {
	it('formatea con dos decimales', () => {
		expect(pipe.transform(10)).toBe('$10.00');
	});
});

2012-actual

Mocha + Chai y sintaxis BDD flexible

Muy extendido en proyectos JavaScript de Node y tooling backend. Mocha corre la suite y Chai define aserciones. Sigue vigente en muchos repos. 

describe('cart total', () => {
	it('suma precios correctamente', () => {
		expect(total).to.equal(42);
	});
});

2013-actual

Selenium / Protractor para flujos E2E

Impulsó la automatización E2E de negocio completo. Protractor perdió tracción, pero Selenium/WebDriver sigue presente en muchas empresas. 

it('permite iniciar sesión', async () => {
	await browser.get('/login');
	await element(by.css('[name="email"]')).sendKeys('ana@demo.com');
	await element(by.buttonText('Entrar')).click();
	expect(await browser.getCurrentUrl()).toContain('/dashboard');
});

2017-actual

Cypress y experiencia de desarrollo visual

Auto-waiting, time-travel y depuración visual integrada. Sigue siendo fuerte en front-end puro. 

it('crea una tarea', () => {
	cy.visit('/tasks');
	cy.findByRole('button', { name: 'Nueva tarea' }).click();
	cy.findByLabelText('Título').type('Preparar release');
	cy.contains('Guardar').click();
	cy.contains('Preparar release').should('be.visible');
});

2018-actual

Testing Library + Jest/Vitest

Se prioriza semántica y accesibilidad sobre estructura interna. La sintaxis representa interacción real del usuario. 

it('abre el modal al hacer clic', async () => {
	render(<SettingsButton />);
	await userEvent.click(
		screen.getByRole('button', { name: /configuración/i })
	);
	expect(screen.getByRole('dialog')).toBeInTheDocument();
});

2020-actual

Playwright y ejecución unificada

Paralelismo, multi-navegador y trazas completas para CI/CD. Convive con Cypress y Selenium según contexto. 

test('checkout completo', async ({ page }) => {
	await page.goto('/shop');
	await page.getByRole('button', { name: 'Comprar' }).click();
	await expect(page.getByText('Pago confirmado')).toBeVisible();
});
