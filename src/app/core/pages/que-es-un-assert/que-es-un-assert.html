¿Qué es una aserción?

Una aserción es una comprobación automática que valida si una condición se cumple. Si la condición es falsa, el test informa del fallo. Es la forma de convertir una expectativa en una verificación.

Definición breve

En testing, una aserción responde a una pregunta concreta: "¿Esto ocurrió como esperaba?"

Si la respuesta es sí, el test pasa. Si la respuesta es no, la aserción muestra un mensaje para entender qué se rompió.

Símiles fuera de programación

Control de acceso a un cine

La regla es simple: "si tienes entrada válida, pasas". La aserción sería comprobar esa regla para cada persona.

Receta en cocina

Si la receta dice "hornear 20 minutos", al final verificas si el bizcocho está hecho. Esa verificación final es una aserción.

Semáforo en la calle

"Con luz roja, los coches se detienen". Comprobar que se detienen es validar la regla: eso también es una aserción.

Ejemplos muy sencillos con console.assert

console.assert no lanza error por defecto, pero muestra un mensaje en consola cuando la condición es falsa.

math-assert.example.js

const result = 2 + 2;
console.assert(result === 4, '2 + 2 debería ser 4');

age-rule-assert.example.js

function canEnter(age) {
  return age >= 18;
    }

console.assert(canEnter(20) === true, 'Con 20 años debería poder entrar');
console.assert(canEnter(16) === false, 'Con 16 años no debería poder entrar');

text-assert.example.js

const title = 'Tests Front End';
console.assert(title.includes('Tests'), 'El título debería contener la palabra Tests');

Idea clave

Una aserción es la pieza central de un test: sin aserciones, solo ejecutas código; con aserciones, verificas comportamiento de forma objetiva.
